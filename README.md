# Road Damage Detection System

## Description
This project detects road damages such as:
- Potholes
- Cracks
- Alligator cracks
- Raveling
- Edge cracks

## Technologies Used
- Python
- OpenCV
- NumPy

## How to Run
1. Install dependencies:
   pip install opencv-python numpy

2. Run the program:
   python main.py

## Output
Processed video and detected frames will be saved in the output folder.
